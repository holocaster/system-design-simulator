System Design Simulator

Três direções para a reforma visual

Cada bloco abaixo é a mesma tela — paleta, barra de controle, canvas com sete componentes e painel de propriedades — desenhada em uma linguagem visual diferente. A simulação mostrada é a mesma nos três: 12.000 RPS, a API degradada em 72% e o Postgres sobrecarregado, para dar de ver como cada paleta se comporta sob estresse. Escolha uma direção; os detalhes finos vêm depois.

Direção A — Console

O simulador como painel de observabilidade. Fundo quase preto, números em monoespaçada, cores de saúde saturadas contra o escuro. Denso e sério: quem olha entende que veio para ler medições.

  • Ponto forte: as cores de saúde brilham; o olho vai direto ao componente em sofrimento.
  • Custo: o React Flow precisa de tema escuro próprio, e a prosa longa da avaliação por IA pede cuidado de contraste.
  • Risco: escuro demais pode cansar em sessão longa de leitura de texto.

Direção B — Prancheta

Herança de desenho técnico: grade milimetrada, cantos retos, traço fino, azul de nanquim. O nó é um bloco de diagrama com faixa de severidade na borda esquerda. Quem olha entende que veio para desenhar uma arquitetura.

  • #12242F traço
  • #12557F acento
  • #1D7A45 ok
  • #A56A06 atenção
  • #B3261E crítico
  • Ponto forte: menor risco de implementação — o React Flow já nasce claro e o texto denso lê bem.
  • Custo: as cores de saúde precisam ser escuras para contrastar no claro, então "gritam" menos que na direção A.
  • Risco: a estética técnica pode ficar árida para quem está aprendendo.

Direção C — Estúdio

Ferramenta de aprendizado, não console de produção. Cantos generosos, sombras suaves, tipografia maior, barras de utilização gordas e legíveis, acento violeta. Convida a mexer em vez de intimidar.

  • #221D34 texto
  • #5A49D6 acento
  • #12886A ok
  • #C07A10 atenção
  • #D1435B crítico
  • Ponto forte: a barra de utilização vira o dado principal do nó — é ela que ensina saturação.
  • Custo: menos densidade: cabem menos números na mesma área, e o canvas fica mais "macio" para um app de medição.
  • Risco: arredondado + violeta é a estética mais datável das três.
